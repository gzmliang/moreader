MoReader（墨阅）是一款典雅、隐私优先的 EPUB 与 PDF 阅读器，内置语音朗读。打开书籍即可在舒适、可自由调整的版式中阅读或听书，支持句子级声画同步、双语对照与章节精读工具。无需注册，无广告，无数据分析追踪。

阅读
- EPUB 书籍，可重排显示，排版完全可调：字体、字号、行距、页边距与字距。
- PDF 文档，保留原始版面。
- 注音支持：拼音与振假名注音与文字上下对齐渲染。
- 四种阅读主题：浅色、羊皮纸、护眼绿与深色。
- 支持 Chrome 与 ChromeOS，包含 Chromebook 设备。

PDF
- 支持 PDF 原版版面阅读，可缩放、整页自适应与平滑滚动。
- 图片型与扫描版 PDF 均可正常渲染，教材与旧文档同样适用。
- 选中任意文字即可朗读或翻译。
- 可将 PDF 转换为排版清爽、可重排的 EPUB，方便阅读与听书。

朗读
- 双层同步：高亮当前段落，同时逐句点亮正在朗读的句子。
- 可选浏览器内置音色（可离线），或云端自然神经音色。
- 朗读速度可在 0.5x 至 2.0x 之间调节。
- 朗读前自动清洗注音标签、括号与脚注引用。
- 点击任意句子即可从该句开始朗读。

精读工具
- 按需选择篇幅的章节摘要。
- 双语阅读：左右对照、仅原著语言、或仅目标语言。
- 人物关系图谱与情节时间线。
- 章节自测题并附解析。
- 笔记与摘要可导出为 EPUB 或 PDF。
- 生成内容本地缓存，再次查看无需等待。

云同步（可选）
- 通过 WebDAV 同步阅读进度、书签与高亮：坚果云、Nextcloud 或您自建的服务器。
- 仅向您自行配置的服务器发起请求，且全程 HTTPS 加密。

您的书籍属于您自己
- 书库、阅读进度、书签与笔记均保存在浏览器本地。无追踪，无数据分析。

说明：朗读默认使用浏览器内置语音引擎，可离线工作；如需云端朗读，可在设置中自行配置服务地址。
